# hgp-codes
Visualizing Hypergraph Product Codes

I saw [this talk]([url](https://www.youtube.com/watch?v=MqGBwQjS4CI)) which explains qLDPC codes and presents an animation to visualize hypergraph product codes.

This visualization tool has the following interesting features:
1. We can find logical operators of the HGP code by "pushing" the codewords of the classical codes. e.g. suppose i look at the classical code C_2. it has n bits. suppose i select 2 of those n. (upon selection it should light up in some color, say sky blue). then, if i just "slide that down" into any row of the qubits below it, then it gives a logical operator of the HGP code
